# Codepictures

An opinionated code screenshot utility.

Edit code directly in the preview and export it as a PNG. Use **Format code** in
the toolbar to pretty-print TypeScript, TSX, JavaScript, JSON, HTML, or CSS with
two-space indentation. Invalid code stays unchanged and displays an error.
Formatting is unavailable for Python, Rust, Go, Shell, and plain text.

Choose GitHub, Catppuccin, or Solarized in the theme menu, then select light or
dark mode. Theme colors apply to the code window and exported PNG.
